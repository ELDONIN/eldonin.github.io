# Roadmap

## Новые проекты

- Сайт: разложение вращать курсором, чтобы время шло (овощи → рыба → животное → человек).
- Сайт: вырезать органы из живого человека.
- Сайт: бегать курсором за убегающим огоньком (при поимке — вспышка, огонёк ускоряется).
- Обработчик изображений в стилях ASCII, dithering, halftone dots.
- Рендер STL-моделей в ASCII.

## Фиксы

- Отрисовка границ фигуры для читаемости.
- Визуальное отображение yaw и pitch.
