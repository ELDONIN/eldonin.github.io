# Требования

Требования к сайту и его реализации описаны в `migration.md`:

- **Часть I (разделы 1–9)** — требования: поведение, дизайн, контент.
- **Часть II (разделы 10–21)** — реализация: стек, архитектура, код, тесты, деплой.

При расхождении частей правильной считается **Часть I**.

Кратко:

- Тёмная тема (единственная), без свечения.
- Разделы: Playground, Articles, Links.
- Полностью статический сайт на GitHub Pages.
- Язык интерфейса — английский, контента — русский.
- Проекты — React-компоненты (canvas через `CanvasHost`, DOM через хуки `shared/lib/host`).
- Статьи — Markdown (Obsidian-совместимый) с KaTeX, диаграммами Mermaid и встраиваемыми проектами.
